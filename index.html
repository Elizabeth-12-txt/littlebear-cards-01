⚠ 存储受限

你现在是双击本地文件或微信里打开的，浏览器不允许本页面使用大容量存储（IndexedDB），所以：
• 聊天记录、字卡、日记、留言可能无法保存
• 关掉页面后数据可能丢失
怎么解决：
把这个 HTML 文件放到一个网址上打开，例如：
python3 -m http.server 8000 npx serve .
或者上传到 Cloudflare Pages / Vercel / Netlify / GitHub Pages，用 https 网址打开。
用网址打开后，容量按磁盘剩余空间算，几百MB到几GB，够用。
